# Pravilo: Praćenje context windowa

Nakon svakog odgovora procijeni koliko je context window popunjen.
Kada procijeniš da je context window popunjen 90% ili više, upozori korisnika sljedećom porukom na početku odgovora:

⚠️ **Context window je blizu maksimuma (~90%+). Preporučujem otvaranje novog chata kako bi se izbjeglo gubljenje konteksta. Prije toga možeš me zamoliti da napravim sažetak trenutnog stanja za novi chat.**
